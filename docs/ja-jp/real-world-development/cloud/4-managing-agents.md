前の 2 つの演習では、Copilot cloud agent にユーザー エクスペリエンスの改善や機能追加に関する 3 つのタスクを依頼しました。cloud agent は自律的かつ非同期に動作しますが、タスクを監視することも重要です。

cloud agent に割り当てたタスクを管理するツールはいくつかあります。その 1 つが GitHub.com の[エージェント ページ][agents-page]です。このミッション コントロールでは、オープンなプルリクエスト (PR) があるエージェント タスクを確認できます。実行された操作を調べたり、進行中のセッションに追加の指示を出したりできます。

この演習では、次の操作を行います。

- エージェント ページで cloud agent のタスクを監視します。
- 進行中のセッションに指示を追加し、機能を拡張します。

## シナリオ

エージェントに高コントラスト モードを依頼した後、チームはライト モードも追加するよい機会だと気付きました。サイトのスタイル更新と切り替え機能の追加をすでに進めているため、ライト モードも含めるのが自然です。エージェントの作業を調整し、ライト モードと高コントラスト モードの両方を追加してもらいます。

## Copilot cloud agent のタスクを確認する

Copilot cloud agent に割り当てたすべてのタスクの現在の状態を確認しましょう。

1. [Copilot エージェント ページ](https://github.com/copilot/agents)に移動します。
2. メイン ペインと左ペインの両方でタスクの一覧を確認します。Copilot に割り当てた次のようなタスクが表示されます。
   - コードベースのドキュメントを更新する
   - ゲーム変更用のアプリケーション プログラミング インターフェイス (API) を生成する
   - Web サイトに高コントラスト モードを追加する
3. 実行中のタスクを選択し、Copilot が行った操作を確認します。次のような作業があります。
   - リポジトリからコードをチェックアウトする
   - Copilot の作業環境を準備する
   - Model Context Protocol (MCP) サーバーを設定する
   - 割り当てられたタスクを完了するための各種操作を実行する

> [!NOTE]
> 表示される手順は、Copilot の作業状況や採用した方法によって異なります。

4. 右側に表示される PR ペインも確認します。ここから PR と変更されたファイルを確認して、作業をさらに監視できます。

## cloud agent に指示を追加する

実行中のタスクを確認したので、Copilot が高コントラスト モードに取り組んでいる間にライト モードも追加するよう依頼します。

1. 高コントラスト モードに関するセッションを選択します。正確なタイトルは Copilot が付けた名前と作業状況によって異なります。

   ![ミッション コントロールのアクセシビリティ セッション](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了して作業が始まるまで、数分間セッションを確認します。以下のようなメッセージが表示されたら、作業が始まっています。
3. **Steer active session while Copilot is working** ダイアログに次のプロンプトを入力します。

   ```plaintext
   高コントラスト モードの作業とあわせて、ライト モードも追加してください。このモードの切り替え機能も用意し、ユーザーが希望する表示モードを選べるようにしてください。
   ```

   ![エージェント ページの cloud agent タスクで、実行中のセッションに指示を追加するダイアログを強調表示した画面](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> キーを押してプロンプトを送信します。
5. Copilot がプロンプトを受け取り、作業に取り込むことを確認します。

## Copilot に作業を任せる

前と同じように、Copilot は更新されたタスクに取り組みます。メッセージを送信した時点で作業中だった手順が終わると、新しい依頼をワークフローに加えます。

今回も完了まで数分かかります。学んだことや確認したことを振り返りながら、少し休憩しましょう。

## まとめと次のステップ

この演習では、GitHub Copilot cloud agent のタスクを監視して方向付ける中心的な場所である Copilot エージェント ページを確認しました。このミッション コントロールでは、進行中および完了したタスクを追跡し、実行内容を確認し、進行中のセッションに追加の指示を出して範囲を調整できます。

次の内容を確認しました。

- ミッション コントロールとエージェント ページで cloud agent のタスクを監視する
- 進行中のセッションに追加の機能を依頼する

Copilot がアクセシビリティ機能の作業を続けている間に、[Copilot が作成した PR を反復して改善します][next-lesson]。
