使用真实场景、完整应用和共享待办列表，在整个软件开发生命周期中实践 GitHub Copilot。通过迭代工作来规划更改、编写代码、测试行为、审查拉取请求，并使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家虚构公司，为桌游提供众筹服务，并采用开发者主题。团队的待办事项已登记为 GitHub 问题，随时可以领取。内容包括筛选和分页等功能，以及无障碍和编码标准等质量改进。

## 选择工作环境

无论你在哪里工作，都可以使用 GitHub Copilot。选择适合你开发方式的环境。每个研讨会都会单独介绍环境设置，并使用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理助手。体验 Plan 和 Autopilot 模式、指令、技能、自定义代理、Playwright MCP、Agent Merge 和实用的斜杠命令。

### [GitHub Copilot 应用][app]

并行运行多个代理会话、切换会话模式、在 Canvas 中协作，并在桌面应用中管理 GitHub 问题和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub 问题分配给异步代理，引导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 代理模式、MCP 服务器和自定义代理。
